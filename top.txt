The QUOTA column holds the seat type (OPEN, OPEN (W), OBC(W), NTC(W), etc.)
The PersonalCat is the candidate's own category (OBC, NTC, SEBC, ...).

category token before the "NNNN:CollegeName" part of the line.

# ─────────────────────────────────────────────────────────────────────────────
# Primary line regex
# Columns (space-separated):
#   Sr#   AIR   NEET-Roll   CET-Form   Name(multi-word)   Gender(M/F)
#   PersonalCat(1-2 tokens)   Quota(1-2 tokens)   ColCode:ColName
#
# We anchor from the RIGHT on the ColCode:ColName so the greedy Name field
# consumes everything up to the last [MF] before the code/quota block.
# ─────────────────────────────────────────────────────────────────────────────
_FLEX_RE = re.compile(
    r"^\s*\d+\s+"              # Sr No
    r"(\d+)\s+"                # group 1: AIR rank
    r"\d+\s+"                  # NEET Roll No
    r"\d+\s+"                  # CET Form No
    r".+?\s+"                  # Name (non-greedy up to last M/F)
    r"[MF]\s+"                 # Gender
    r"(.+?)\s+"                # group 2: PersonalCat + Quota block
    r"(\d{4})\s*:\s*(.+)$"     # group 3: ColCode, group 4: ColName
)
